# Fájlrendező

Python script, ami kategóriák (képek, dokumentumok, telepítők, tömörítettek, zene/videó) szerint rendezi egy mappa fájljait. Linux Minten készült.

## Használat

    python3 rendezo.py              # Letöltések, próbafuttatás
    python3 rendezo.py ~/Képek      # másik mappa, próbafuttatás
    python3 rendezo.py --eles       # tényleg mozgat

Éles módban naplót vezet (naplo.txt). Cron-nal időzíthető.
